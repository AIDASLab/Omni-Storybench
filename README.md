# Omni-StoryBench project page

Source of the GitHub Pages site for *What Comes Next? Omni-StoryBench for Evaluating Story-Grounded
Omnimodal Generation* ([arXiv 2609.37317](https://arxiv.org/abs/2609.37317)). This is the `gh-pages`
branch of [AIDASLab/Omni-Storybench](https://github.com/AIDASLab/Omni-Storybench); the code lives on `main`.

```
index.html                  project page
static/                     CSS, JS, logos, and paper figures (static/images/paper/)
viewer/                     dataset viewer (served at /viewer/)
  index.html, viewer.js, viewer.css
  data/                     generated by tools/build_viewer.py; do not edit by hand
tools/
  viewer_selection.json     curated example ids shown in the viewer, with rationale and attribution
  viewer_baselines.json     baseline configurations whose outputs the viewer shows
  build_viewer.py           builds viewer/data/ from the dataset snapshot and baseline outputs
```

## Preview locally

The viewer loads `viewer/data/examples.json` with `fetch`, so open the site through a local server
rather than `file://`:

```bash
python3 -m http.server 8000   # then open http://localhost:8000/
```

## Rebuild the viewer data

1. Download the dataset snapshot:
   ```bash
   uv run --no-project --with huggingface_hub python -c "from huggingface_hub import snapshot_download; \
     snapshot_download('snu-aidas/Omni-StoryBench', repo_type='dataset', local_dir='/path/to/Omni-StoryBench')"
   ```
2. Edit `tools/viewer_selection.json` (examples) or `tools/viewer_baselines.json` (systems) if needed, then:
   ```bash
   H=/path/to/evaluation_harness
   uv run --no-project --with pandas --with pyarrow --with pillow --with imageio-ffmpeg \
     python tools/build_viewer.py --dataset /path/to/Omni-StoryBench \
       --outputs $H/baselines --results $H/results
   ```

The build stops on any mismatch. It checks each selected sample's JSON against the parquet index, and
checks each run's `dataset_manifest.json` (output index to sample id) against the parquet order. Baseline
outputs are picked with the same file-resolution rules as the evaluation harness (`src/common.py`), so
the viewer shows the files the judges scored. Missing outputs are shown with the reason the generation run
logged. Per-sample LLM-judge scores are read from `<results>/<run>/stage_<n>/<type>/all_results.json`
(stages 1-3 are the three judges of each evaluation type). Images are converted to JPEG and audio to MP3
(with the static ffmpeg bundled in `imageio-ffmpeg`).
Samples from Storybooks Canada, and any example whose license is non-commercial, are rejected.

## Deploy

Repository settings → Pages → *Deploy from a branch* → `gh-pages`, folder `/ (root)`.
The site is then served at `https://aidaslab.github.io/Omni-Storybench/`. `.nojekyll` disables Jekyll processing.
